# Étude de concurrence ARMD
## Analyse structurelle de 7 sites de référence

**Date** : 27 mai 2026
**Sites étudiés** : Forward Global, Concerto PR, Vectors Group, Strat Gov Advisors, Narrativ Global, Geopolitique.eu, Stears
**Méthode** : WebFetch + analyse architecture, hero, fondateur, expertises, cases, partners, DA
**Objet** : nourrir la V3 du mockup ARMD avec un positionnement informé

---

## 1. Architecture site (sections, ordre)

| Site | Architecture observée |
|---|---|
| **Forward Global** | Enjeux → Services & Technologies → Talent → Group → News |
| **Concerto PR** | Le groupe → Expertises → Implantations → Références → Insights → Ventures → Contact → Newsletter |
| **Vectors Group** | Home → Our Approach → Agency → Expertises |
| **Strat Gov Advisors** | Home → Solutions → Publications → About Us → Contact |
| **Narrativ Global** | Services → Our Approach → Brands → Contact |

**Pattern dominant pour cabinets conseil influence** : *Positionnement → Expertises → (Implantations) → Références → Insights → Contact*. Concerto PR a l'architecture **strictement la plus proche** de ce qu'ARMD veut faire (8 sections priorisées au brief).

Diriger."** dans aucun hero - ce triptyque appartient à la brochure ARMD mais pas à la home.

## 3. Traitement du fondateur / leadership

| Site | Présence du fondateur en home |
|---|---|
| Forward Global | **Absent** (gouvernance enterrée dans niveau "Group") |
| Concerto PR | **Absent en home**, "L'équipe" via "Le groupe" niveau 2 |
| Vectors Group | **Absent**. "Diverse and multicultural" sans noms |
| Strat Gov | **Absent**. Simple "Meet our team" link |
| Narrativ Global | **Totalement absent**. Studio présenté en entité |
| Geopolitique.eu | **1900 contributeurs** en index alphabétique (volume comme social proof) |
| Stears | **Absent entièrement** |

**Insight stratégique majeur pour ARMD** : **aucun concurrent direct n'affiche son fondateur en home.** Goudet en se positionnant comme pilier visible **rompt avec le code du marché** et crée une **vraie différenciation**. Cela aligne avec :
- Le brief : "Goudet est l'élément de social proof principal"
- Le dossier §3.4 : "Mécanique d'autorité V1 fondée sur Goudet et les partenaires"
- La proposition §2.5 : "Page fondateur structurée pour porter ton parcours public"

Ce contre-pied n'est pas une déviation, c'est **le pari narratif d'ARMD**. Goudet n'est pas un employé interchangeable d'une firme anonyme, c'est un fondateur qui prend la responsabilité publique de son cabinet. C'est rare dans ce marché et c'est crédible.

## 7. Visual style

| Dimension | Pattern dominant |
|---|---|
| Palette | Neutre (whites, grays) ou dark navy (Stears). Pas de couleur primaire vive. |
| Typographie | Sans-serif clean, hiérarchie classique. Pas d'extreme weights. |
| Motion | **Très peu ou pas du tout**. Forward, Concerto, Vectors, Strat Gov, Narrativ : statique. Stears, Geopolitique : statique. |
| Densité | **Spacieuse**, generous whitespace |
| Imagerie | Carousels statiques (Concerto), photographie workspace (Vectors). Pas de 3D, pas de Vanta-like. |

**Insight critique pour ma V2** : **j'ai surchargé en motion**. Vanta dots + tilt 3D + lighting interactif sur cards = trop "tech startup" pour ce marché institutionnel. Le code du marché est la **sobriété**, presque l'ennui. Une institution multilatérale veut du calme, pas du wow.

**Décision pour V3** : garder **un seul moment signature** (le splash ARMD→ARMED, qui est le moment de marque) et **calmer le reste du site**. Pas de Vanta dots dans le hero. Pas de tilt 3D sur les cards. Garder le pointer-tracked lighting subtilement, mais réduit. Plus de typographie monumentale et moins d'effets.

## 8. Différenciateurs ARMD vs concurrents

Ce qu'ARMD doit garder du code marché :
- Hero texte fort + sous-titre (pas de vidéo)
- Architecture sections : positionnement → expertises → implantations → références → insights → contact
- Visuel sobre, statique, généreux en whitespace
- 3 piliers thématiques (Donnée · Récit · Humain) - format Concerto-like

Ce qu'ARMD peut prendre à contre-pied :
- **Mettre Goudet visible en home** (différence majeure, aucun concurrent ne le fait)
- **Lister les médias activables et partenaires structurels** (Concerto liste juste implantations)
- **Insights ouvert dès V1** avec 1-2 articles fondateurs (rare en V1 chez les concurrents)
- **OSEA en preview** (positionnement think tank, différenciateur fort)
- **Cartographie monde projetée** (antennes futures) au lieu d'une liste de bureaux

Ce qu'ARMD invente :
- Le splash ARMD → ARMED comme moment de marque (jamais vu chez les concurrents)
- Le narratif "souveraineté informationnelle depuis l'Afrique" (couplage absent chez tous)

## 9. Architecture V3 recommandée pour ARMD

Inspirée Concerto PR (plus proche) + différenciée par Goudet pilier.

```
01  HERO                       Phrase positionnement + sous-titre + meta
02  FONDATEUR (NOUVEAU)        Goudet : photo, bio, missions phares, parcours
03  NOTRE APPROCHE             Donnée · Récit · Humain (3 piliers sobres)
04  NOS EXPERTISES             6 expertises, grille sobre
05  NOS IMPLANTATIONS          Cartographie projetée Paris + Abidjan + antennes
06  NOS RÉFÉRENCES             3 cas anonymisés (REasy, Manuel Ntumba, Huawei)
07  CELLULE OPÉRATIONNELLE     5 collaborateurs + lien Advisory Board
08  NOS PARTENAIRES            Médias activables + cabinets partenaires (marquee)
09  INSIGHTS                   2-3 articles preview + OSEA preview
10  NEWSLETTER                 Capture audience simple
11  CONTACT                    Abidjan + Paris + email + téléphone
```

**Différence majeure avec V1/V2** : ajout sections **02 Fondateur** + **05 Implantations** + **07 Cellule opérationnelle** + **09 Insights** + **10 Newsletter**. Soit 5 sections oubliées en V2.
